# Multiplication Adventure

Multiplication Adventure is a colourful mini-game that helps children learn their multiplication tables while collecting coins and unlocking badges. Each round presents a new multiple-choice challenge with instant feedback and encouraging messages.

## Getting Started

1. Install Flutter from [flutter.dev](https://flutter.dev).
2. Run `flutter pub get` in this directory to fetch dependencies.
3. Start the app with `flutter run`.

### Oyun Özellikleri

- Çocuk dostu ve renkli çoktan seçmeli çarpım soruları
- Doğru cevaplar için yıldızlar ve rozetler kazandıran ödül sistemi
- İlerlemeyi, doğru cevap serilerini ve rozetleri kalıcı olarak kaydeder
- Motivasyon sağlayan geribildirim mesajları ve ipuçları
